# KomekStud Telegram боты

Бот: https://t.me/komekstudkz_bot

## Мүмкіндіктері
- 💰 Қызметтер мен бағалар (сайттағыдай)
- 🛒 Тапсырыс беру: жұмыс түрі → көлемі → антиплагиат → тақырып → мерзім → аты → телефон.
  Бот болжамды бағаны есептейді, тапсырыс `ADMIN_CHAT_ID` чатына келеді.
- 📋 Жұмыс кезеңдері, ✅ кепілдіктер, 📞 байланыс
- `/id` — чат ID-ін көрсетеді (ADMIN_CHAT_ID білу үшін)

## Баптау
1. `.env.example` файлын `.env` деп көшіріп, `BOT_TOKEN` жазыңыз. `.env` GitHub-қа жүктелмейді.
2. Ботты қосып, оған `/id` деп жазыңыз. Шыққан санды `ADMIN_CHAT_ID`-ге жазыңыз
   (топқа келсін десеңіз, ботты топқа қосып, сол жерде `/id` жазыңыз).
3. Ботты қайта қосыңыз.

## Іске қосу
```bash
pip install -r requirements.txt
python bot.py
```
Немесе Docker: `docker build -t komekstud-bot . && docker run --env-file .env komekstud-bot`

Бот үнемі қосулы тұруы керек, сондықтан оны сервер/хостингте (Railway, Fly.io, VPS т.б.)
`BOT_TOKEN` және `ADMIN_CHAT_ID` айнымалыларымен іске қосыңыз.

Бағаны өзгерткенде `bot.py` ішіндегі `SERVICES` пен сайттағы `script.js`-ті бірге жаңартыңыз.
