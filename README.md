# KomekStud (КөмекСтуд)

Студенттерге оқу жұмыстарын дайындау, өңдеу және рәсімдеу бойынша онлайн қызметтің қазақша сайты.

## Құрылымы
- `index.html` — бет (Біз туралы, Қызметтер мен бағалар, Жұмыс кезеңдері, Шарттар, Тапсырыс беру)
- `styles.css` — стильдер (алдымен телефонға бейімделген)
- `script.js` — мобильді мәзір, баға калькуляторы, тапсырысты WhatsApp-қа жіберу

## Іске қосу
Ешқандай орнату қажет емес — `index.html` файлын браузерде ашыңыз.

## GitHub Pages
`main` тармағына әр push кезінде `.github/workflows/pages.yml` сайтты автоматты түрде жариялайды.
Бір реттік баптау: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
